# GoDex

Pokémon GO companion tracker sister app to KantoList.

## Project direction

GoDex is a standalone manual-first Pokémon GO companion app. It shares visual DNA with KantoList but uses a different data model focused on Pokémon GO collection tracking, wishlists, trade lists, shiny tracking, and future companion tools.

## Current plan

- V0.1: manual Kanto test shell
- V0.2: deeper Pokémon GO database layer
- V0.3: trade/wishlist expansion
- V0.4: stats and filters
- Later: raid/friend/task planning and official API research only if safe/approved
